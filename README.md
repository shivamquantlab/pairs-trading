# Pairs Trading

## Research question
Can a formation-only linear hedge ratio and a past-window spread z-score be translated into a signal without fitting on the trading period?

## Methodology and formulas
The formation window estimates log(y_t)=alpha+beta*log(x_t)+epsilon_t by least squares. The beta is frozen for the test period. At time t, the spread z-score compares the current spread with its strictly prior W observations. A state machine enters short spread above the positive entry threshold, long below the negative entry threshold, and exits near zero. The close-t state is applied to the following spread change.

## Assumptions and limitations
- The demo creates a shared synthetic log-price component plus a mean-reverting synthetic residual with seed 101. There are no real securities or market prices. The regression rejects constant formation regressors.
- The strategy is a two-leg unit-exposure illustration; cumulative PnL is in synthetic log-spread units, not portfolio returns.
- It charges an illustrative 3 bp per unit of each leg's absolute notional: the x-leg is scaled by abs(beta), and the final position is liquidated at the sample end. Borrow availability/cost, execution delay, corporate actions, delistings, and survivorship bias are not modeled.
- Cointegration is not formally tested; selecting pairs, thresholds, and windows requires a separate multiple-testing-aware research design.
- Results are not investment performance.

## Installation

Requires Python 3.11 or newer and uv. From the repository root, install the pinned project and test dependencies:

```bash
uv sync --locked --extra test
```

## Usage and reproducibility

Run the fixed-seed synthetic experiment with:

```bash
uv run --locked pairs-demo --seed 101
```

The command uses only synthetic or hand-authored scenarios, writes its chart and `reports/summary.json`, and requires no API credentials. The included report is regenerated by this command.

## Tests and lint

Run the unit suite and Ruff checks with:

```bash
uv run --locked python -m pytest
uv run --locked python -m ruff check src tests
```
